# vs-project
Project Overview

This project explores a dataset of 100,000+ job postings to analyse salary trends and skill demand for remote Data Analyst roles using SQL.
The goal was to answer realistic analytical questions by writing clear, structured queries rather than relying on pre-built dashboards or tools.

Key Questions Answered

The project answers the following analytical prompts:

Retrieve the top 10 highest-paying remote Data Analyst job postings and their associated companies
Identify the most in-demand skills required for the highest-paying remote Data Analyst roles
Analyse skill demand for remote Data Analyst roles with above-average salaries

Each question was first solved independently, then extended by combining logic using Common Table Expressions (CTEs) to demonstrate more advanced query structuring.

SQL Techniques Used:

SELECT, WHERE, ORDER BY, LIMIT
INNER JOIN / LEFT JOIN across multiple tables
Aggregations with COUNT, AVG
GROUP BY and HAVING
Subqueries
Common Table Expressions (CTEs)
Conditional logic using CASE and more

Dataset:
100,000+ job postings
Includes job titles, salaries, remote status, companies, and required skills
Structured across multiple relational tables
Project Structure

Each analytical question is solved in a dedicated SQL query
CTEs are used to improve readability and to combine multiple analytical steps
Queries are commented to explain intent and logic

Key Takeaway

This project demonstrates the ability to:
Translate business-style questions into SQL queries
Work with large, relational datasets
Structure increasingly complex queries in a readable and maintainable way
